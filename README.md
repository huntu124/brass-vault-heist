The Brass Vault — an original top-down heist game for desktop Chrome. Crack the vault (hold E
beside it), grab the loot bags, read the guards' sweeping vision cones and the CCTV cameras'
teal view cones, keep the alarm meter cool, and slip out the getaway door before lockdown.
Three jobs: Storehouse, Courtyard, Vault Wing. Original art, names and WebAudio sound; no
network requests, plain static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

WASD move · SHIFT sneak · hold E to drill the vault · R restart · N next job.
